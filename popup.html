Stream opens muted?

Twitch always starts muted for tabs opened without a direct click, and Chrome only lets scripts unmute it if this browser profile is allowed to autoplay sound on twitch.tv. If a stream Miteruyo opens automatically is muted, open Twitch's sound setting and set it to Allow, then try again.
